# SolveSpace India

GitHub Pages-ready static storefront.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Expected URL: https://Zyphorix7.github.io/solvespace-india/

## Add products
Edit `js/products.js`. Add product images under `assets/products/`. The customer has no product-editing interface.

## Buy Saloma
No fake API or payment integration is included. Obtain the official supported Buy Saloma checkout/API documentation first. Never place private API keys or admin credentials in frontend files or a public GitHub repository. If secrets are required, use a secure backend/serverless function with environment secrets.

## Branding
Official supplied brand assets are under `assets/logo/`. The original sheet is retained for reference and extracted logo variants are used by the site.
